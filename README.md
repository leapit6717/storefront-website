Blush and Luxe Boutique
Website Purpose
Blush and Luxe Boutique is an e-commerce website created by Leah Semaj Pittman for the SDC260 course. The store offers designer-inspired purses, jewelry, sunglasses, wallets, beauty bags, and other feminine accessories. Customers can browse ten products, add products to a persistent shopping cart, adjust quantities, view inventory, apply a coupon, and complete a demonstration checkout.
Pages and Files
- index.html - Store homepage
- shop.html - Responsive product catalog generated by JavaScript
- product-details.html - Featured product details
- cart.html - Interactive shopping cart with quantity and removal controls
- checkout.html - Dynamic order summary, shipping, purchase, validation, and coupon form
- order-confirmation.html - Completed order number, items, and total
- about-contact.html - Store information and validated contact form
- network-test.html - Local network connection test page
- styles.css - External stylesheet linked to every page
- script.js - Products, cart, inventory, local storage, validation, coupon, and checkout logic
- images - Product images

Interactive Features
- Displays ten products with a JavaScript loop
- Uses a responsive product layout
- Adds products to a functional shopping cart
- Displays product names, prices, quantities, item totals, and cart total
- Increases, decreases, removes, and clears cart items
- Saves cart contents and inventory through browser refreshes with local storage
- Reduces stock when an item is added and restores stock when it is removed
- Disables sold-out products and displays an Out of Stock tooltip
- Validates required contact form fields
- Validates shipping and purchase fields
- Checks whether a coupon code exists
- Applies a 20 percent discount with coupon code BLUSH20
- Completes checkout and displays order confirmation details
- Displays success and error messages
Network Connection Test Features
- Displays the local host name
- Displays the current communication port
- Displays the current transmission protocol
- Displays the previous time the Network Connection Test page was launched
- Uses local storage to save the previous launch time
- Confirms when the local network connection is recognized successfully
- Works with the VS Code Live Server extension
