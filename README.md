# Blush & Luxe Boutique

## Website Purpose

Blush & Luxe Boutique is an e-commerce website created for my product development course. The website allows customers to browse designer-inspired purses, jewelry, sunglasses, wallets, beauty bags, and other feminine accessories.

The purpose of the website is to provide customers with an organized and easy-to-use online shopping experience. Customers can view products, read descriptions, add items to their cart, and continue to checkout.

## Pages Included

- Store Homepage
- Shop
- Product Details
- Shopping Cart
- Checkout
- About and Contact
- Order Confirmation

## Brand Theme

The website uses a feminine and elegant boutique design. The main colors are burgundy, rose pink, blush pink, soft cream, and white.
